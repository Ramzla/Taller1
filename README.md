Sistema de Playlist en Java.
UABC - Facultad de Ingeniería | Ingeniería en Computación
José Osvaldo Ramírez Lara

Descripción:
Programa de consola en Java para administrar una playlist de música mediante un menú interactivo. Aplica conceptos de Programación Orientada a Objetos (POO), listas dinámicas (ArrayList), entrada de datos (Scanner), ciclos y condicionales con validación de entrada.

Funcionalidades:
Agregar canción: Guarda título, artista y duración.
Mostrar canciones: Lista todas las canciones registradas.
Eliminar canción: Permite borrar una canción por su número de lista.
Buscar canción: Búsqueda por título.
Cantidad de canciones: Muestra el total acumulado.
Validación de datos: Evita errores si el usuario ingresa texto en campos numéricos.
Resumen final: Muestra el nombre de la playlist y el total de canciones al salir.

Estructura del Código:
Cancion.java: Modelo con los datos de cada canción.
Playlist.java: Gestión y métodos de la lista (ArrayList).
Main.java: Menú principal y lectura de consola.
